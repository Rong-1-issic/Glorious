# content studio｜跨境内容工作台

面向 AI＋出海黑客松的本地工作台。原仓库活动网站保持不变，本应用单独位于 `content studio/`，不会随原 Pages 工作流发布。

## 启动

需要 Node.js 20.9+（已验证 Node 24）、npm。首次使用：

```bash
cd "/workspace/Glorious/content studio"
npm ci
npm run dev -- --port 3000
```

浏览器打开本机 3000 端口。生产运行：

```bash
npm run build
npm run start -- --port 3001
```

无需账号、数据库、外部 API 或密钥。不要同时对同一 `.next` 目录执行多次生产构建。未配置模型调用和在线抓取，界面明确提示；没有伪造平台连接、AI 成功、合规结论或实验数据。

## 可操作流程

1. 载入演示项目，或创建空项目并设置市场和产品。
2. CSV/文本导入评论，预览映射后选择追加或替换；最大 2 MB、5000 条累计原始记录。保留去重评论的完整来源；演示与真实评论禁止混合。CSV 支持 BOM、双引号、逗号与跨行字段；单行错误不阻断其他有效记录。
3. 单词、二词、三词英文频次分析；可编辑停用词、搜索并点击查看精确原评论。支持人工洞察及最多三个重点问题。
4. 编辑品牌事实和来源、人工核对状态，添加文化转译策略并确认。
5. 演示预设可生成三种结构。演示包含明确标为虚构的人物、地方及信息整理流程资料；各版只引用已有事实。缺少或修改相应资料时，对应预设停止生成并要求补证，不凭旧模板补写。工序版描述信息整理流程，不冒充生产工艺。真实导入数据使用人工草稿，不会套用演示结果。
6. 双语逐句编辑、关联事实/评论、规则检查、选择版本、快照记录和原句派生。内容改变使检查失效；上游或策略变更使受影响草稿过期，需重新确认策略及逐稿复核，之后重新检查。
7. 导出 Markdown 内容包、完整 JSON、所有版本句子映射 CSV、实验卡 CSV。JSON 可回导，校验版本、结构和引用 ID。CSV 文本单元格防公式执行。

数据仅保存在当前浏览器 `localStorage`（键 `storybridge-v1`），不上传服务端。刷新可恢复，多项目隔离；浏览器清理可能删除数据，请导出备份。删除项目需确认，不删除已下载文件。用户输入由 React 以文本渲染，不执行 HTML；来源链接仅允许 HTTP/HTTPS。评论内指令不执行。文件下载位置由浏览器控制。

## 验证

```bash
npm run typecheck
npm test
npm run build
# 先启动生产服务于 3001；浏览器测试需要 Python Playwright 和 /usr/bin/chromium
python3 tests/browser.py
```

`lib/core.test.ts` 覆盖 CSV、否定短语、来源、限制、缺失材料、规则与引用校验。浏览器测试覆盖演示完整流程、自定义 CSV、精确追溯、跨模块传递、检查失效、刷新及项目切换、导出、桌面与手机布局。

## 边界

- 无在线采集适配器、无模型 API 调用、无服务端存储、无协作或登录。
- 词频是英文规则分析；其他市场可以填写，但没有专属法规/语言规则。
- 证据检查仅为启发式编辑建议，不验证材料真伪，不完成语义蕴含或全面翻译审查，不保证合规。商家手动关联证据及人工核对仍然必要。
- 事实资料支持表单/TXT；不解析 PDF、扫描件或办公文档，不自动翻译评论。
- 派生内容使用原句摘录；实验卡手动录入，无自动投放、统计判胜或虚构指标。没有足够数据时显示“暂不能判断”。
- 暂未实现 PDF 导出、真实模型生成、逐字版本差异与自动用户调研。

## 交付文件

- `examples/`：经验证的完整虚构演示项目及 Markdown、CSV 导出样例，可直接回导。
- `docs/screenshots/`：实际浏览器桌面和手机截图。
- `VALIDATION.md`：自检记录。
- 运行依赖与构建缓存不提交；在本目录执行 `npm ci` 后按上方命令启动。
- 浏览器测试可通过 `BASE_URL`、`CHROMIUM_PATH`、`TEST_OUTPUT_DIR` 指定服务、浏览器和输出位置；默认输出 `test-results/`。
