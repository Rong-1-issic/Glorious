# WowLand百校造百岛·【宁波大学】站

静态活动网页，所有图片、样式和交互均包含在根目录 `index.html` 中，无需安装依赖或运行构建服务。

发布使用 GitHub Pages。仓库 Settings → Pages → Build and deployment 的 Source 选择 **GitHub Actions** 后，向 `main` 推送更新，或在 Actions 中手动运行 **Publish website to GitHub Pages**。

工作流仅发布网页和旧路径跳转文件，不发布仓库中的原始宣传图片。旧地址 `Glorious/index.html` 会跳转到网页根路径。
