## 1. 先记录约束

本次背景：宁波大学、大二、新媒体部部长；有官方推文、调研及活动文案、问卷设计、SPSS、电商评论分析经验，具备 Python 基础和简单绘图能力；接触过文旅调研、校园宣传及跨境消费课题。希望积累可展示作品，优先内容与数据分析结合的岗位。

实习安排按 **2027 年 1 月 18 日—2 月 6 日、2 月 14 日—21 日**处理。年份由检索时点推定，后续使用需再确认。两段合计 28 个自然日，中间间隔 7 天；不能写成连续一个月、28 个工作日或保证满足“满一个月”。地点接受宁波本地或线上。

优先筛选新媒体、文旅内容、品牌文案、校园活动运营，其次是用户调研与内容数据分析。把以下条件分开记录：年级、专业、城市、远程、最短周期、每周出勤、技能要求、薪资、内容产出及投递入口。远程不代表短期，零基础不代表接受大二，“寒假实习”标签不代表接收指定日期。

先读取可用环境配置，再对实际目标发起只读 HTTPS 请求。当前配置与草稿须区分，保存草稿不等于已应用网络设置。需要白名单时保留已有条目，仅补充所需域名；若保存结果要求发布，用户须在环境设置完成相关保存与发布，再实际复查。

本次所需域名：`www.shixiseng.com`、`www.zhaopin.com`、`www.zhipin.com`、`www.nowcoder.com`、`www.51job.com`、`www.baidu.com`。它们是本次配置记录，不保证未来仍已放行，也不涵盖所有跳转或详情域名。

## 3. 先搜列表，再看详情

实习僧已跑通的入口示例：

```text
https://www.shixiseng.com/interns?keyword=新媒体&city=宁波
https://www.shixiseng.com/interns?keyword=内容运营&city=宁波
https://www.shixiseng.com/interns?keyword=文旅&city=宁波
https://www.shixiseng.com/interns?keyword=用户研究&city=宁波
https://www.shixiseng.com/interns?keyword=新媒体&city=全国&months=1
```

`months=1` 在本次页面中显示为“一月”周期筛选，有效缩小到短期岗位。全国列表可能显示企业所在城市，但正文写远程；宁波列表也可能混入全国远程岗位，要按详情核对。翻页时记录页码与覆盖范围，不把首屏检索说成全站爬取。

智联已核对的城市路径：`jl654` 为宁波，`jl653` 为杭州。必须查看页面标题及岗位地点，不能只相信猜测的城市代码。本次杭州结果保留在证据归档中，但未当作宁波推荐。

从列表读取公开详情链接，再低频逐条或少量并发访问。本次临时抓取曾使用最多 5 路并发；后续遵守网站条款、robots 与访问限制，遇到限流应停止并诊断。无需登录即可读取的范围已足够完成本次检索；不抓取私人联系方式、登录态或凭据。

## 4. 抓取和核验

在仓库根目录运行，例如使用一个新的输出目录：

```bash
python3 '寒假实习/scripts/fetch_public_page.py' \
  'https://www.shixiseng.com/intern/inn_egteuxavrh9f' \
  --name lang --out /workspace/outputs/recruiting-new-check
```

脚本使用浏览器常见 User-Agent、30 秒超时、默认 TLS 校验及平台代理。保留 HTML，提取可见正文和相关详情链接，记录 URL、处理时间与哈希；不将 HTTP 200 自动标为岗位有效，不覆盖同名文件。重新核验须用新目录，避免旧文件混入新结果。

本次列表中的数字和部分职位名称使用私用区字体编码，文本里会出现乱码。优先用详情页正常可读的工资、天数、月份及正文交叉核对，不能凭乱码猜数值。新脚本会标记私用区字符，仍需人工检查正文。JS 占位或登录页也必须人工识别。

每个详情至少核对：

1. 企业、岗位、原始详情链接，以及页面是否包含实际职位描述。
2. 页面刷新时间、截止日期，区分刷新时间和首次发布时间；很久未刷新但截止日期较晚的页面列作旧线索，不能直接称为当前在招。
3. 远程与本地、是否接受大二、专业与技能限制、连续周期及每周出勤。
4. 页首与正文薪资差异、固定工资与绩效、实际工时。矛盾处原样注明，不自行选较高值。
5. 原创文案、调研、复盘等作品产出，与私域引流、个人账号代发、无薪积分任务分别判断。平台知名不等于已验证企业可信度。
6. 是否明确接收本次寒假时间及中间间隔；未提及统一标“待确认”，不能靠标签推断。

本次发现的典型情况：Calmfident 页首与正文薪资有差异，敏思跃动正文明确无薪，信福达主要要求个人实名账号代发；均已降低优先级。万康智药正文投递邮箱不完整，未将其作为有效投递入口。宁波本地微思诺德相关岗位多要求 3 个月，未列入短期首选。

## 5. 整理结论与留证

先按硬条件筛除，再解释能力匹配，使用“优先咨询 / 周期不符 / 旧线索 / 重复 / 待确认”等具体状态，避免没有依据的精确匹配分。

清单记录页面事实与人工判断，输出 UTF-8 BOM CSV 方便 Excel 打开，并提供简短 Markdown 说明。重复公司同类岗位标注城市或出勤差异，不靠不同链接重复推荐。报告说明已取得哪一层证据：列表、详情、雇主回复各自分开。

如需询问雇主，先由用户确认通过自己账号联系；本次只提供咨询话术，未代发。重点询问 2027 寒假名额、两段时间能否累计、工时与计薪、企业账号、带教安排、脱敏作品展示权。

## 6. 离线复现本次结果

以下命令在仓库根目录执行，不请求网络：

```bash
python3 -m zipfile -e '寒假实习/2026-10-24/本次采集原始文件.zip' \
  /workspace/scratch/recruiting-replay-20261024
python3 '寒假实习/scripts/export_snapshot.py' \
  --source /workspace/scratch/recruiting-replay-20261024 \
  --output /workspace/outputs/recruiting-replay-20261024
python3 '寒假实习/scripts/fetch_public_page.py' \
  'https://www.shixiseng.com/intern/inn_egteuxavrh9f' \
  --source-html /workspace/scratch/recruiting-replay-20261024/lang.html \
  --name lang --out /workspace/outputs/recruiting-offline-20261024
```

导出脚本包含本次固定的人工结论与日期，生成的 CSV 和说明应与归档版本逐字节一致。它不能把新抓取页面自动归类为“仍在招”，未来需另建日期目录、重新核验并更新结论。抓取脚本离线模式只证明解析能力，不表示复查了线上招聘状态。
